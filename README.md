# igv-lesson

A hands-on introduction to visualizing genomic data with the
[Integrative Genomics Viewer (IGV)](https://igv.org) desktop application:
loading reference genomes, navigating the genome at different zoom levels,
inspecting aligned reads and candidate SNPs, precomputing coverage with
`igvtools`, exploring RNA-seq splice junctions and Sashimi plots, and
exploring population variant data from a VCF file.

Built on [The Carpentries Workbench][sandpaper-docs] lesson template. See the
lesson template documentation for instructions on formatting, building, and
publishing lesson material.

Exercises and example data adapted from IGV workshop materials (exercises,
slides, and sample datasets) originally developed for the BroadE Workshop by
Jim Robinson and Helga Thorvaldsdóttir.

[sandpaper-docs]: https://carpentries.github.io/sandpaper-docs/
